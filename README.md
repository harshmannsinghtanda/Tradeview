# TradeView — Professional Trading Journal & Analytics 📈⚡

TradeView is a modern, high-performance, dark-mode trading journal and terminal built with **React 18, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons**. 

Designed for both **rapid-fire day traders / scalpers** and **methodical swing traders**, it runs 100% locally in your browser with zero cloud tracking, ensuring your financial data remains completely private.

---

## 🌟 Key Features

- 🌓 **Dual-Theme Engine**: Bloomberg/Linear-style Obsidian Dark Mode & crisp Light Mode with a 1-click instant toggle.
- ⚡ **Scalper Mode**:
  - **Quick-Strike Bar**: Sub-3 second keyboard-driven trade logging (`Tab` + `Enter`).
  - **Prop Firm & Tilt Circuit Breaker**: Real-time daily loss monitoring, overtrading frequency tracking, and session cooldown locks.
- 📊 **Executive Dashboard**:
  - Net Realized P&L, Win Rate %, Profit Factor, Average Win / Loss, Max Drawdown.
  - Interactive **Cumulative Equity Curve** with hover crosshair inspection.
  - Color-coded **Calendar Heatmap** (Daily profit & loss tracking).
  - Market Exposure breakdown across **Crypto, Stocks, Forex, Futures, and Options**.
- 🧠 **Psychology & Strategy Analytics**:
  - Track emotions (*Disciplined, Patient, FOMO, Revenge, Hesitant, Greedy*).
  - Pinpoint costly emotional leaks and most profitable setups.
- 📁 **Universal CSV Importer & Backups**:
  - Drag-and-drop CSV importer compatible with generic spreadsheets, Zerodha, Binance, MetaTrader, and IBKR.
  - 1-Click JSON backup and CSV spreadsheet exports.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or pnpm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/tradeview.git

# Navigate into project directory
cd tradeview

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## 🌐 Deploying to the Web (Free)

This is a static, local-first web application that can be deployed to **Vercel**, **Netlify**, or **GitHub Pages** for free.

### Deploy on Vercel:
1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select this repository and click **Deploy**.
